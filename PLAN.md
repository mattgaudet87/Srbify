Srbify App Plan
Oct 1, 2026  ·  @Matt
Srbify is a mobile-friendly web app for looking up casual Serbian fast: search any word in
English or Serbian from the top bar, or browse by category, and every entry shows the
Serbian, pronunciation, meaning, alternatives, and exactly how it changes depending on
who's talking and who or what it describes.
1. What it is
A personal Serbian phrasebook for texting, built for a male English speaker texting a
female Serbian speaker. It's a lookup tool first: open it, type or tap, copy the phrase, paste
it into a text.
Rules every entry follows
Latin alphabet only, never Cyrillic.
Casual spoken Serbian by default. Formal or polite versions are listed as alternatives,
not the main answer.
Ekavian (Serbia) spelling is the main form (lepo, gde). The ijekavian version (lijepo,
gdje) is shown as a note when it differs, so you recognize it if you see it.
Plain-English pronunciation on every Serbian line, with the stressed syllable in capitals
(VOH-leem).
Every entry says whether it changes. Either a "Never changes" badge, or a clear table
of every form and when to use it.
Default view = your forms. The app highlights the form a man uses when talking about
himself, and the form for a woman when describing her. A setting lets you flip this.
Register is always labeled: neutral, casual, slang, or vulgar, so you never send a swear
by accident.
Accuracy: content may be AI-generated, so every entry has a "verified by a native
speaker" checkmark that starts off unchecked.
2. Screens and layout
Five screens, phone-first, with the search bar pinned to the top of every one.

Never changes is its own badge, and just as important: šta, baš, ludilo, važi, sumnjam are
safe to use anywhere.
How it's shown on screen
On list rows: up to 3 small badges, so you can spot "careful, this one changes" at a
glance.
On the entry: a forms table with columns for the tags that apply, plus a "Use when"
column in plain English ("you, about yourself" / "her, about herself" / "you, describing
her").
Highlighting: based on Settings, the row matching "me (male) talking to her (female)" is
highlighted, so the right answer is always obvious.
Each forms table ends with a one-line pattern hint when there is one ("Female form
usually adds -a").
Other things worth flagging on entries
Look-alikes: words that look similar but mean different things (što = why, not what).
False friends: nezgodan means awkward, not "not hot."
Tone: literal meaning vs how it actually lands (jebote literally means f*** you, but works
like "damn").
Fused negatives: nisam, nemam, neću that don't follow the normal ne + verb rule.

How results look
Each result row: English, Serbian, pronunciation, and its category in small grey text.
If the match came from a variant or alternative, say so: "Umorna sam (female form of
I'm tired)."
No results: show "No match yet" and the closest suggestions.

Technical note for Claude Code: normalize both the search text and the data the same
way (lowercase, strip accents, map đ to dj) before comparing, and use a fuzzy search
library (such as Fuse.js) for typo tolerance.
7. Build plan and Claude Code prompt
Build it in 4 phases, testing on your phone after each one.
Tech choices (keep it simple)
React + Vite, a plain static website: no login, no database, no server.
All content in one JSON file ( src/data/entries.json ) following section 5.
Fuse.js for search.
Deploy on Vercel from GitHub, so every update goes live automatically.
Settings and favorites saved in the browser (localStorage), since it's just for you.
